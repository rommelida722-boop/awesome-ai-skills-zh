# 审查试用：跨调用污染任务列表

输入为 examples/review_bad.py。审查脚本命中 F-001 对应的共享状态风险以及裸 except、异常吞噬，实际定位由 JSON 输出记录。

## 已确认问题

`collect` 的默认 `items=[]` 在函数定义时创建。依次调用 collect("甲")、collect("乙") 时，第二次得到 ["甲", "乙"]，第一次返回的列表也被修改。若业务期望每次创建独立结果，这会导致任务间数据混入。最小修复：默认值改为 None，函数内新建列表；显式传入列表时是否原地修改需由业务契约决定。

裸 except 会捕获中断与退出。只在已知失败可恢复时捕获对应异常；不能直接忽略所有异常。保留原函数输入和返回约定后再讨论修改，本次评测不自动改写目标。

## 局限

三条局部规则不能发现全部业务错误。例如 average.py 中若故意将平均值改成总和，AST 审查脚本仍返回无发现；需要业务测试或 Agent 阅读契约才能识别。
